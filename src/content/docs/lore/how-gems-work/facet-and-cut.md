<span class="ia-label in-world">In-World</span>

Every Gem made in a Gempire kindergarten is given a Facet & Cut code when they emerge. The code isn't unique to one Gem. It marks the batch they came out of, so Gems who emerged together in the same batch share the same code. Some of them treat that like being family. Others would rather not talk about it.

*United Frontier Gems and Cubic Zirconias don't have a Facet & Cut.*

## Facet

**1st character:** the Diamond who made the Gem.

| Code | Diamond |
| --- | --- |
| `0` | Alpha Black |
| `0B` | Omega White |
| `1` | Theta Gold |
| `01` | Metal Society |
| `2` | Epsilon Blue |
| `3` | Nightshade Violet |
| `4` | Maroon Red |
| `5` | Bi-Colored Kandy |
| `6` | Saturn Light |

**2nd character:** the first letter of your kindergarten's name.

**3rd character:** your rank, without the decimal. *A Rank 4.2 Gem uses `42`.*

**4th character:** any letter you like.

## Cut

**1st character:** your ATK after your Era modifier. *Level growth doesn't count.*

**2nd character:** `X`

**3rd character:** any letter you like.

## Example

A Hessonite made by Maroon Red, emerged at the Militia Kindergarten, Rank 2.1, with 11 ATK after her Era modifier:

- **Facet:** `4` `M` `21` + `O`
- **Cut:** `11` `X` `X`
